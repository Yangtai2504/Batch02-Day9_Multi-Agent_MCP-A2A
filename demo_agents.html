Q1 — Latency tổng của hệ thống là bao nhiêu?

Sau khi chạy uv run python test_client.py, latency đo được là 93 giây (baseline, sequential). Sau khi áp dụng parallel dispatch, latency giảm xuống còn 73 giây.


Baseline (~93s): 5 LLM calls tuần tự — analyze_law(20s) → check_routing(8s) → call_tax(20s) → call_compliance(20s) → aggregate(20s) + overhead(5s).

Sau optimize (~73s): 3 calls song song → bottleneck = compliance(30s), sau đó aggregate(25s) + overhead(7s).
Lý do parallel mỗi branch mất ~30s thay vì 20s: 3 request đồng thời cạnh tranh Gemini API làm mỗi call chậm hơn chút, nhưng tổng vẫn nhanh hơn vì không chờ nhau.
